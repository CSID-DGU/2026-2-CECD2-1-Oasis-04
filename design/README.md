# design

> 이 폴더는 frontend/ 코드가 아니다. 레퍼런스 이미지는 외부에 공유하지 않는다.

## 폴더 용도

| 폴더 | 용도 |
|---|---|
| `before/` | 지금 화면 스크린샷 (고치기 전 기록) |
| `after-tokens/` | 2단계 후 스크린샷: 토큰을 디자인 문서 값으로 맞추고 Pretendard 를 넣은 뒤 (2026-11-16) |
| `after/` | 최종 화면 (2026-11-20, 옮기기 계획 13단계). 14화면 + UNAVAILABLE 이유별(`UNAVAILABLE-<이유>`), 들은 말 없음(`-empty`), 경로 고르기 2·3번(`ROUTE_GUIDE-pick2·3`), QR 2번 경로(`QR_HANDOFF-route2`), 버스 정류장 첫 화면(`IDLE-bus`). 1920×1080, 시계 2026-11-19 오후 2:30, 움직임 줄이기. 예전 2단계 중간 기록은 git 기록에 있다 |
| `compare.html` | `before/` 와 `after/` 를 같은 이름끼리 나란히 보는 페이지. 파일을 그대로 열면 된다 (인터넷 없이) |
| `references/` | 현장 사진과 참고 화면 (팀 내부용) |
| `mockups/` | 시안 페이지. `confirmed/`(확정), `wip/`(작성 중), `archive/`(폐기·제안·과정), `shared/`(공통 파일). 자세한 것은 `mockups/README.md` |
