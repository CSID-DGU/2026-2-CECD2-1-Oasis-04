# 시안 일관성 점검 (2026-11-19)

- 대상: `design/mockups/confirmed/` 의 확정본. `overview.html` 의 `SCREENS` 31칸(상태 14개 + 변형)을 모두 쟀다. `band-thin.html` 은 README 대로 예전 배치의 예시라서 뺐다
- 고친 것: 없음. 이 문서만 새로 만들었다
- 재는 방법: Playwright(Chromium)로 창 1920×1080, `file://` 로 열고 글꼴을 다 읽은 뒤 브라우저가 계산한 값(`getBoundingClientRect`, `getComputedStyle`, `document.getAnimations()`)을 읽었다. 움직이는 화면은 `?freeze=` 로 멈춰서 쟀다. 좌표는 화면 왼쪽 위 기준 px, 소수 첫째 자리까지
- 눈으로 확인한 것: 요약 판 두 개(QR_HANDOFF, ROUTE_GUIDE 경로 1개)를 오른쪽 칸만 잘라 찍어 비교했다 (아래 10번). 그 밖은 숫자만 읽었다
- 모든 화면이 가로 1920, 세로 1080 으로 스크롤이 없다
- 표시: **기준** = 대부분의 화면 값. **의도(문서 N절)** = 디자인 문서에 이유가 있음. **확인 필요** = 문서에 이유가 없음. **문서와 다름** = 화면끼리는 같은데 디자인 문서의 값과 다름
